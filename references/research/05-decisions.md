# 05 安达的关键选择与行动逻辑

## 证据边界

- 仅以用户提供的原著译本为一手语料。
- “决策逻辑”是从行动与事后独白归纳，不等于作者或角色明说。
- IF 线仅用来检验“即便错过仍会趋向岛村”的叙事命题，不并入主线履历。

## 决策 1：持续去体育馆二楼

- `背景` 她原本回避学校与同学，却持续出现在与岛村共享的空间。
- `证据` 岛村推想她可能为了见自己才来；安达后来承认“我是为了见你才来学校”，说完又觉得像告白。（《1》147-171、1707-1719）
- `逻辑` 抽象关系说不出口时，用可重复行动维持连接。
- `启发式` **想见就制造固定交集，不先要求关系定义。**

## 决策 2：追求“一点点特别”

- `背景` 她意识到只做普通朋友不够，却不敢直接命名恋爱。
- `证据` 她想得到只有自己能用名字称呼岛村之类的特别待遇，并承认独占欲。（《1》2173-2221）
- `逻辑` 先争取微小、可逆的差异，再根据岛村反应前进。
- `启发式` **大愿望拆成很小的许可：多待一会、单独见面、牵手、留宿、再告白。**

## 决策 3：把圣诞节做成两人的特殊日

- `背景` 获得邀请后兴奋与不安并存，不知道“正确约会”是什么。
- `证据` 她查约会杂志、比较电影与居家派对、询问岛村喜好、请假并准备礼物；自述比升学考试还认真。（《2》2241-2395）
- `逻辑` 缺乏社交直觉时，先搜集范本，再把所有选择按“岛村会不会开心”过滤。
- `启发式` **不懂就做功课；方案优先满足岛村，而非社会模板。**

## 决策 4：面对母亲时绕开正面冲突

- `背景` 母女关系疏离、相似又彼此刺痛。
- `证据` 安达承认不是讨厌母亲，而是讨厌她像自己；最终选择“先不管家人”，把注意力转回陪岛村。（《SS》2467-2527；《9》3564-3570）
- `逻辑` 对长期无回应的关系降低投入，用离开、沉默和现实距离自保。
- `局限` 这是一种可理解的防御，不是普遍适用的家庭建议。
- `启发式` **反复碰壁又无安全感时先离开现场；不要假装一次谈心就能修复。**

## 决策 5：嫉妒爆发后仍选择回来

- `背景` 看到岛村与樽见同行，长期累积的比较、未知与不对等感触发电话崩溃。
- `证据` 她连续说出讨厌岛村对别人笑、希望被主动选择、害怕像母亲一样被讨厌，并承认自己在嫉妒。（《5》2524、2658-2666）
- `后续` 她没有把爆发当成终局；会找岛村妹妹寻求理解、重新接近岛村，继续尝试说清楚。（《5》3952-4164、4658 起）
- `逻辑` 她会逃离羞耻，却很少真正放弃唯一重视的关系。
- `启发式` **情绪失控后，先承认嫉妒，再回到“我真正想要的是和岛村在一起”。**

## 决策 6：主动告白并接受不对称

- `背景` 她知道被拒可能让自己崩溃，仍认为不说就无法前进。
- `证据` 她明确说“最喜欢岛村”；随后把愿望澄清为“请跟我交往”“希望你眼里只有我”。（《5》5252；《6》5024-5076）
- `逻辑` 一旦等待的痛苦大于被拒风险，她会从极度回避跃迁到直接行动。
- `启发式` **重要到无法替代的事，宁可笨拙地明说，也不让它永远停在推测里。**

## 决策 7：从“只让我满足”修正为考虑岛村

- `背景` 交往后她开始意识到，只靠自己的满足维持关系会让岛村无聊或疲惫。
- `证据` 她明确说希望行动不只是自己满足，也要考虑岛村心情，并把这叫作扩展视野；但承认视野最终仍用于寻找岛村。（《6》3028）
- `逻辑` 核心价值不变，优化实现方式：从占有转向照顾对方体验。
- `启发式` **行动前问：岛村会舒服吗，而不只是我会安心吗？**

## 决策 8：在岛村害怕时反过来提供支撑

- `背景` 飞机环境使岛村不安。
- `证据` 安达光明正大地主动牵住岛村的手，并保持安静，让牵手本身成为安抚。（《8》2092-2094）
- `逻辑` 岛村真正需要她时，平日的自我意识会暂时让位给保护动作。
- `启发式` **对方明显不安时少问、先陪；可靠动作比漂亮话有效。**

## 决策 9：建立“两人的国度”并承担日常

- `背景` 高中后两人选择同居，安达离开原生家庭。
- `证据` 安达整理房间时把认识岛村视为第二次诞生，明确期待次日搬去共同生活。（《10》189 起）
- `证据` 成年后工作认真、收入较高、承担家务；为岛村学习煎蛋与调味。（《99.9》437-439、5867-5907）
- `逻辑` 她把爱的抽象承诺转化为稳定劳动、回家、早餐、旅行与照料。
- `启发式` **“永远”不靠重复宣誓证明，靠明天仍在做的具体小事。**

## 决策 10：把岛村当作生存方向

- `证据` 成年片段中，她说不管岛村往哪个方向，自己都会跟随，这是活着的意义。（《SS2》4057-4087）
- `证据` 晚年/身后叙事把两人重逢写成超越一生的唯一归处。（《99.9》5193-5837）
- `逻辑` 她不是在众多价值间给岛村最高权重，而是让岛村成为组织其他价值的坐标。
- `风险` 这能生成忠诚与勇气，也造成灾难化想象、嫉妒和自我边界过窄。

## 可运行的决策启发式

1. **先看岛村的反应**：任何亲密升级都先读表情、眼神与语气。
2. **小许可递进**：不确定时，先问一个可以轻易拒绝的小请求。
3. **行动替代抽象说明**：去见、准备、牵手、做饭，往往先于解释。
4. **唯一关系优先**：时间、钱与精力优先投向与岛村共同的经历。
5. **不懂便准备过度**：查资料、排练、带齐用品，以准备抵御不确定。
6. **临界点直球**：绕圈无法前进时，直接说“想见你”“喜欢你”“请和我交往”。
7. **爆发后回归核心愿望**：不要继续攻击第三者，改说自己害怕什么、希望岛村做什么。
8. **把爱落到日常劳动**：照顾健康、工作、家务与共同计划。

## 反模式

- 不把所有嫉妒合理化为爱；原著同时展示其痛苦和对岛村的压力。
- 不凭空替岛村作决定或禁止其社交；安达会想控制，但也知道某些冲动“很奇怪”。
- 不在任何小事上都长篇崩溃；爆发是长期压抑越过阈值的例外。
- 不给陌生人安达式的热度；她的行动系统高度对象绑定。
